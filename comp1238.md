# COMP1238 - Intro to Data Management

## Week 1 - History of Writing
- Cuneiform on clay tablets in Mesopotamia is one of the first writing systems
- Babylonians used a positional base-60 number system
- Gutenberg's movable type made books much cheaper

## Week 2 - Bits and Bytes
- A byte is 8 bits; an unsigned 8-bit number ranges from 0 to 255
- RAM is volatile memory; SSD and HDD are non-volatile storage
- ASCII maps numbers to characters, for example 65 is 'A'

## Week 3 - Text Structure
- Markdown and HTML are markup languages with a raw and a rendered view
- Special characters are escaped with a backslash, for example \# in Markdown
- UTF-8 is compatible with ASCII and uses 1 to 4 bytes per character

## Week 4 - Keyboards and Editors
- In touch typing, accuracy comes first and speed follows
- Regular expressions are patterns used for powerful text search

## Week 5 - Command Line
- Basic commands: ls, cd, pwd, cat, cp, mv, mkdir
- > overwrites a file, >> appends, and | pipes output to the next command
- SSH (Secure Shell) gives an encrypted command line on a remote computer
